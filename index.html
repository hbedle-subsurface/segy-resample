Each section is drawn with its own fixed gray scale, clipped at the 99th percentile of absolute amplitude. The red line marks the trace shown below each section and the red bracket marks the time window of that trace plot. In the trace plots, dots are the input samples and the line is the resampled trace.

Method

Each trace is Fourier transformed, the spectrum is extended with zeros above the Nyquist frequency of the input sampling, and the inverse transform returns the trace at the finer sample interval. This is band-limited (sinc) interpolation. The input samples reappear unchanged in the output, and no frequencies above the input Nyquist frequency are created. Only the part of each trace needed for the chosen window, plus a 0.5 s tapered margin, is transformed.

When a first and last CDP are given, every trace header is read once to find the traces whose CDP number lies inside the range (both ends included), and only those traces are resampled and written. The CDP number is read from the chosen header bytes, which are 21 to 24 in the SEG-Y standard. Selecting by CDP number does not assume that the numbers increase along the file. Setting the output interval equal to the input interval gives a crop without interpolation.

Start and end times are true times. The first input sample is taken to be at the delay recording time of the first trace header (bytes 109 and 110), so a line whose traces start at 1.0 s is cropped at 1.0 s, not at 0. By default the output traces keep their true time by writing the new start time into the delay recording time of every trace header (the old value plus the amount cropped off the top). Some software ignores that header word and plots the first sample at 0 s. For that case the other choice writes zeros from the original start of the traces down to the start time, so the data sit at their true times with no header setting needed, and the files are larger by the zero samples.

The output is written as 32-bit IEEE float (format code 5) with the byte order of the input. The binary header sample interval, samples per trace and format code are updated. Each trace header is copied with its samples per trace and sample interval updated, and with the delay recording time increased by the start time when the traces are cropped at the top. All other trace header values, including CDP numbers, coordinates and trace sequence numbers, are unchanged, so the cropped line keeps its original CDP numbering. The 3200-byte textual header is copied as it was, so any sample interval or format it states refers to the original file.
